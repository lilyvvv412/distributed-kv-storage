# DistributedKV Evidence Dashboard

Open `index.html` directly in a browser, or serve the repository with a
static server:

```bash
cd "/Users/lilyluo/Downloads/Project*3/DistributedKvStorage"
python3 -m http.server 8080
```

Then visit <http://localhost:8080/evidence-dashboard/>.

The page is intentionally static. It links to the reproducible Markdown
reports already generated by the project and does not pretend to be a live
cluster control plane.
